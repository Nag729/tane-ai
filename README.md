# たねAI 🍏

質問に答えるだけで、会議の準備ができる。

## 概要

- **決める会議**: みんなで決断しよう
- **伝える会議**: 大切なことを届けよう
- **話し合う会議**: アイデアを育てよう

質問を通じて情報を整理し、構造化された会議資料を生成します。

## 使い方

```
[1] 会議タイプを選ぶ
    └─ 決める / 伝える / 話し合う

[2] 初期情報を入力
    └─ テーマ（何について）
    └─ 補足情報（参加者、背景、制約など）

[3] AI の質問に答える
    └─ 選択肢から選ぶ or 自由入力
    └─ AI が「十分」と判断 → 「資料完成」ボタン出現

[4] 会議資料が完成
    └─ AIでフィードバック → 再生成も可能
    └─ コピーして Slack / ドキュメントに貼る
```

## ジョブ理論による整理

### メインジョブステートメント

「会議を開く前に、AI と壁打ちして事前資料を作りたい。そうすれば、参加者が準備して来て、会議の時間を有効に使える。」

### 会議タイプごとのジョブ

#### 決める会議

- **When**: 何かを決める必要があるとき
- **I want to**: 選択肢・メリデメ・推奨案を整理したい
- **So I can**: 参加者が事前に考えて来て、会議で効率的に決定できる

#### 伝える会議

- **When**: 情報を全員に伝える必要があるとき
- **I want to**: 伝えるべき内容と期待アクションを整理したい
- **So I can**: 伝え漏れなく、参加者が何をすべきか理解できる

#### 話し合う会議

- **When**: 意見を出し合って議論したいとき
- **I want to**: 論点と前提情報を整理したい
- **So I can**: 参加者が事前に考えて来て、議論が深まる

### 感情的ジョブ

- 「資料なしで時間を無駄にしたくない」という不安を解消したい
- 会議準備という堅苦しいタスクを、楽しくこなしたい
- 「準備が整った」という達成感を得たい

### 競合する既存の解決策

| 解決策                    | 課題                         |
| ------------------------- | ---------------------------- |
| 自分で資料を作成          | 時間がかかる、構造化が難しい |
| テンプレートを使う        | 機械的で、状況に合わせにくい |
| ChatGPT/Claude にベタ打ち | 毎回ゼロから説明が必要       |
| 資料なしで開催            | 会議時間が無駄になる         |

### このプロダクトが勝てる理由

| 機能                      | 解決するジョブ                             |
| ------------------------- | ------------------------------------------ |
| 会議タイプの選択          | 目的に合った資料構造を自動提案             |
| 選択肢 + カスタム入力形式 | 「何を書けばいいか」が分かる、抜け漏れ防止 |
| AI が動的に質問を生成     | 自分では思いつかない視点を得る             |
| 会議タイプ別の構造化出力  | そのまま使える資料が完成                   |
| ストリーミング表示        | 待ち時間のストレスを減らす                 |
| 遊び心のあるデザイン      | 会議準備の堅苦しさを和らげる               |

### 4 つの勝ちポイント

1. **入口が整理されている**: 会議タイプ選択 → 初期情報入力で迷わない
2. **選択肢で答えやすい**: 選ぶだけで考えが整理される
3. **深い思考力**: Extended Thinking による適切な質問生成
4. **そのまま使える出力**: 会議資料として完成度が高い

## コアとなる体験

**「AI に質問されて答えていくうちに、資料ができている」**

- AI が主導権を持って質問してくる
- ユーザーは受動的に答えていく
- 答えていくうちに、自然と資料が完成する

この「会議資料の作成というゴールに即した質問が AI から来る」という体験が、ChatGPT/Claude を直接使うのとの最大の差別化ポイント。

## 成功の定義（MVP）

- 「自分で書くより、AI に聞かれて答える方が早く・深い資料ができる」と感じる
- 「この質問されなかったら抜けてた」という体験が生まれる
- 会議を開く前に、自然と使いたくなる

## セットアップ

```bash
# 依存関係インストール
npm install

# 環境変数設定
cp .env.example .env.local
# ANTHROPIC_API_KEY を設定

# 開発サーバー起動
npm run dev
```

http://localhost:3000 でアクセス
